# Лабораторная работа №2 — Добавление интерактивности в визуализацию данных с использованием D3.js

Продолжение [лабораторной работы №1](https://github.com/Nursatdeveloper/d3js-lab1-bitcoin).
Страница загружает CSV-файл с метриками сети **Bitcoin** и строит два графика
на [D3.js](https://d3js.org/) v7. В этой работе графики стали интерактивными:
при наведении курсора показывается подробная информация о записи, а выбранный
элемент визуально выделяется.

## Что добавлено в работе №2

### Всплывающие подсказки (tooltip)

**Столбчатая диаграмма** (столбец = год), характеристики в подсказке:

| Характеристика | Пример |
|---|---|
| идентификатор — год | 2022 год |
| основное значение — среднее за год | $28,294 |
| минимум и максимум за год, с месяцем | $16,956 (12.2022) / $41,941 (04.2022) |
| изменение к прошлому году | ▼ −40,1 % |
| категория — награда за блок | 6.25 BTC (в годы халвинга: 12.5 → 6.25) |
| количество месяцев в данных | 12 |

**Линейный график** (точка = одна запись CSV, т. е. месяц):

| Характеристика | Пример |
|---|---|
| идентификатор — месяц | Июнь 2023 г. |
| основное значение показателя | $27,426 |
| изменение к прошлому месяцу | ▼ −0,5 % |
| категория — награда за блок | 6.25 BTC |
| цена BTC (если выбран другой показатель) | $27,426 |

Награда за блок — категориальный параметр, вычисленный из даты: 12.5 BTC до
халвинга 11.05.2020, 6.25 BTC до халвинга 20.04.2024, далее 3.125 BTC.

### Выделение выбранного элемента

- **Столбцы:** наведённый столбец и его подпись остаются яркими, остальные
  становятся полупрозрачными (`opacity: 0.35`).
- **Точки:** ближайшая к курсору точка увеличивается (радиус 3 → 7) и получает
  обводку, остальные бледнеют; вертикальная пунктирная линия отмечает месяц.
  Ближайшая точка ищется через `d3.bisector(...).center`, поэтому попадать
  курсором точно в точку не нужно.
- **Связанные графики:** при наведении на столбец года на линейном графике
  подсвечивается полоса этого года, а при наведении на точку подсвечивается
  столбец её года.

### Информационный блок «Подробно о записи»

Справа от графиков (на телефоне — над ними) выводятся **все пять показателей**
записи под курсором: для месяца — значения из CSV, номер записи и награда за блок;
для года — средние значения и изменение каждого показателя к прошлому году.
Текущий выбранный показатель выделен.

### Осталось из работы №1

Загрузка CSV с обработкой ошибок, преобразование типов, вывод количества записей
и названий столбцов, выбор показателя и фильтр по годам.

## Набор данных

`data/bitcoin_monthly.csv` — среднемесячные показатели блокчейна Bitcoin
с января 2019 по октябрь 2026 года (**94 записи, 6 столбцов**).
Источник — открытый [Charts API blockchain.com](https://www.blockchain.com/explorer/charts).

| Столбец | Тип | Описание |
|---|---|---|
| `month` | дата (`ГГГГ-ММ`) | месяц |
| `price_usd` | число | средняя рыночная цена 1 BTC, USD |
| `transactions_per_day` | число | подтверждённых транзакций в сутки |
| `hash_rate_ehs` | число | хешрейт сети, EH/s (10¹⁸ хешей в секунду) |
| `avg_block_size_mb` | число | средний размер блока, МБ |
| `fees_usd_per_day` | число | сумма комиссий майнерам в сутки, USD |

Скрипт `tools/build_csv.py` воспроизводит файл из API (`python tools/build_csv.py`).

## Запуск

Браузер не разрешает `d3.csv()` читать файл, если страница открыта двойным
щелчком (`file://`), поэтому нужен локальный HTTP-сервер. Из папки проекта:

```bash
python -m http.server 8000
```

и откройте <http://localhost:8000>. Также подойдёт `npx serve .` или расширение
**Live Server** в VS Code. Нужен интернет: D3.js подключается с CDN `cdnjs.cloudflare.com`.

## Как устроена интерактивность (для защиты)

В `js/main.js`:

1. На столбчатой диаграмме поверх каждого столбца лежит невидимый прямоугольник
   `rect.bar-hit` на всю высоту графика — увеличенная зона наведения. На нём
   обработчики `mouseenter` / `mousemove` / `mouseleave`.
2. На линейном графике поверх области построения лежит прозрачный `rect`.
   В `mousemove` координата курсора переводится в дату (`x.invert`),
   `d3.bisector` находит ближайший месяц, его точке задаются класс `is-active`
   и радиус 7.
3. `showTooltip()` заполняет `div#tooltip` HTML-разметкой и ставит его рядом с
   курсором, не выпуская за край окна; `hideTooltip()` скрывает его.
4. Выделение сделано CSS-классами: контейнер получает `is-hovering` (все элементы
   бледнеют), выбранный элемент — `is-active` (остаётся ярким).
5. Объект `linked` хранит функции `highlightBar` и `highlightLineYear`, которые
   каждый график задаёт при отрисовке — так один график подсвечивает элемент на другом.
6. `showMonthInfo()` / `showYearInfo()` заполняют информационный блок через
   d3-привязку данных (`selectAll().data().join()`).
